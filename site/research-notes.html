RESEARCH RECORD / UPDATED 15 NOVEMBER 2026

What the results
can tell us.

ReturnWise is a local research workspace for return-risk estimation and review prioritization. The current evidence supports exploratory comparison only. It does not establish time-safe performance or operational impact.

Current statusNo corrected candidate has a fresh holdout evaluation, deployment refit, or integrated replacement artifact. The saved model remains a historical experimental artifact.

01 / DATASET

Competition data with an unknown time boundary.

The validated local files include 200,000 labeled training rows and 50,000 unlabeled competition test rows. The target is returned. The competition metric is ROC-AUC.

The supplied specification does not establish an event-order timestamp or a feature snapshot cutoff. A random split therefore does not test temporal generalization. The unlabeled competition test file is not used for labeled evaluation.

03 / FEATURE POLICY

Pre-shipment is the working scenario.

Identifiers, target-derived or potentially post-event fields, delivery delay, and customer history without a verifiable time cutoff are excluded from the corrected raw-feature pipeline. This is a research policy based on available documentation, not proof that every retained feature was available at the exact prediction moment.

04 / DECISION USE

Capacity shapes a review list.

The review queue ranks records by a probability already present in the uploaded file. It does not produce fresh estimates. Review capacity limits the number shown in the priority set. Expected counts in the local Python simulator are derived from probabilities and stated assumptions.

A model association does not show that a review causes a return to be prevented or changes profit. A probability is uncertain and should be interpreted alongside human review and operational context.

05 / DEPLOYMENT

The Netlify surface is static.

This page can inspect local CSV files and rank supplied probability columns entirely in the browser. The Python package, Streamlit app, and local joblib artifact are not hosted on this static site. No live inference endpoint is configured.

To continue the research locally, run the Streamlit application from the project workspace. The operational scoring path remains experimental and must not be treated as production validated.
